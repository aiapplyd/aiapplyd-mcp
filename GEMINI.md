# AI Applyd

AI Applyd is an AI job-application agent. This extension connects Gemini CLI to its remote MCP server at `https://mcp.aiapplyd.com/mcp` (OAuth sign-in on first use).

Use it when the user wants to:
- find jobs that match their resume and preferences (`search_jobs`),
- tailor a resume or cover letter for a specific posting,
- apply to a job on the employer's own hiring system,
- check the status of applications they already sent.

Applications count as sent only when the employer confirms receipt. Setup guides for other clients: https://aiapplyd.com/mcps
